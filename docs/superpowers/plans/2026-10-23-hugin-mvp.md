# Hugin MVP – Umsetzungsplan

> **Status: FINAL (v6.2).** Kern T1–T8 unverändert aus v5 (5 Review-Runden, 4 Agenten, OK). Design-Integration T3/T4/T9–T13 + NEU T14–T20: 3 Review-Runden (A/B/C) über dieselben 4 Agenten, alle OK (aiphaistos ✓, aires security-OK ✓, aipollo testbar-OK ✓, aithena designtreu-OK ✓).

> **Für ausführende Agenten:** BENÖTIGTES SUB-SKILL: superpowers:subagent-driven-development (empfohlen) oder superpowers:executing-plans, um diesen Plan Aufgabe für Aufgabe umzusetzen. Schritte nutzen Checkbox-Syntax (`- [ ]`).

**Ziel:** Eine native iPad-App („Hugin"), in der ein KI-Agent per Chat Dateien in freigegebenen Ordnern findet, liest, zusammenfasst, bearbeitet, umbenennt und verschiebt.

**Architektur:** SwiftUI-App mit Agent-Loop (Plan → Werkzeugaufruf → Beobachtung → Antwort), Modell-Abstraktion (`ModelProvider`) mit zwei Implementierungen (Apple Foundation Models on-device, Claude per HTTPS) und reinen Datei-Werkzeugen mit Sandbox-Containment-Check. Build/Tests ausschließlich über GitHub Actions (macOS-Runner), da lokal nur Windows vorhanden ist.

**Tech Stack:** Swift 6, SwiftUI, SwiftData, PDFKit, FoundationModels, URLSession, XCTest, XcodeGen (Projektgenerierung in CI).

**Spec:** `docs/superpowers/specs/2026-10-23-ipad-ki-agent-design.md` – dieser Plan argumentiert aus der Spec; Ausführende lesen beide.

## Globale Randbedingungen

- Swift 6 / SwiftUI; Deployment-Target iPadOS 26.0 (läuft auf dem iPad Air 5 mit iPadOS 27.0.1)
- **Keine externen Dependencies** – ausschließlich Apple-Frameworks
- **Kein Löschen-Werkzeug.** Überschreiben nur mit Nutzer-Bestätigung + automatischem Backup
- **Max. 15 Werkzeugaufrufe pro Auftrag** (AgentRunner)
- Dateioperationen **nur innerhalb** security-scoped Freigaben (Containment-Check `resolve()`)
- Claude-API-Key nur im Keychain, niemals in Code/Repo/Logs; UI- und Kommentarsprache Deutsch
- Claude-Anbindung bewusst **non-streaming** (Spec-Reduktion, Streaming folgt in Phase 2)
- Tests: XCTest, laufen in GitHub Actions (macOS-Runner, iOS-Simulator). **TDD-Anpassung:** lokal kein Swift verfügbar → Test wird vor Implementation geschrieben, Rot-Phase wird im selben CI-Run geprüft (Test schlägt bei falscher Implementierung fehl, Tests sind verhaltensspezifisch). Bei jedem Task: Commit + Push, CI muss grün sein, bevor der nächste Task beginnt.
- Commits: Conventional Commits (`feat:`, `test:`, `build:`, `docs:`)
- CI-Stellschrauben (bewusst): Runner-Image `macos-26`, Simulator-Name im Workflow – anpassen, falls CI sie nicht findet (`xcrun simctl list devices available` steht im CI-Log)

## Nutzerschritte (nicht automatisierbar, in Task 1 und 14 verankert)

1. Gratis-Apple-ID (fertig vorhanden), GitHub-Konto anlegen
2. Privates/public GitHub-Repo anlegen (Empfehlung: public → macOS-CI gratis, Repo enthält keine Secrets), dann: `git remote add origin <URL> && git push -u origin master`
3. Nach CI-Lauf: Artifact `Hugin-unsigned.ipa` herunterladen, per USB mit Sideloadly (Windows) + Apple-ID signieren/installieren (oder über Tailscale an den Rechner übertragen)
4. Auf dem iPad: Einstellungen → Allgemein → VPN & Geräteverwaltung → Entwicklerprofil vertrauen
5. Gratis-Account: App verfällt nach 7 Tagen → Schritt 3 wiederholen; Daten bleiben erhalten

```swift
import Foundation

enum JSONValue: Codable, Sendable, Equatable {
    case null, bool(Bool), number(Double), string(String)
    case array([JSONValue]), object([String: JSONValue])

    init(from decoder: Decoder) throws {
        let c = try decoder.singleValueContainer()
        if let v = try? c.decode(Bool.self) { self = .bool(v) }
        else if let v = try? c.decode(Double.self) { self = .number(v) }
        else if let v = try? c.decode(String.self) { self = .string(v) }
        else if let v = try? c.decode([JSONValue].self) { self = .array(v) }
        else if let v = try? c.decode([String: JSONValue].self) { self = .object(v) }
        else { self = .null }
    }
    func encode(to encoder: Encoder) throws {
        var c = encoder.singleValueContainer()
        switch self {
        case .null: try c.encodeNil()
        case .bool(let v): try c.encode(v)
        case .number(let v): try c.encode(v)
        case .string(let v): try c.encode(v)
        case .array(let v): try c.encode(v)
        case .object(let v): try c.encode(v)
        }
    }
    var stringValue: String? { if case .string(let s) = self { return s }; return nil }
    var doubleValue: Double? { if case .number(let n) = self { return n }; return nil }
    var boolValue: Bool? { if case .bool(let b) = self { return b }; return nil }
    subscript(key: String) -> JSONValue? {
        if case .object(let o) = self { return o[key] }; return nil
    }
    static func from(data: Data) throws -> JSONValue { try JSONDecoder().decode(JSONValue.self, from: data) }
    func data() throws -> Data { try JSONEncoder().encode(self) }
}
```

```swift
import Foundation

struct ToolSpec: Codable, Sendable, Equatable {
    let name: String
    let description: String
    let inputSchema: JSONValue
}

struct ToolCall: Sendable, Equatable {
    let id: String
    let name: String
    let arguments: JSONValue
}

struct ProviderResponse: Sendable, Equatable {
    let text: String
    let toolCalls: [ToolCall]
}

enum ProviderMessage: Sendable, Equatable {
    case user(String)
    case assistant(text: String, toolCalls: [ToolCall])
    case toolResult(id: String, content: String)
}

enum ModelError: Error, Equatable {
    case unavailable      // on-device-Modell fehlt (z. B. CI-Simulator)
    case unauthorized     // Claude-Key ungültig
    case network(String)
}

/// Bestätigungs-Anfrage des Runners an die UI: Pfad + alt/neu für die Diff-Vorschau
struct ConfirmRequest: Sendable, Equatable {
    let path: String
    let oldContent: String?
    let newContent: String
}

protocol ModelProvider: Sendable {
    var name: String { get }
    /// Glut (.local) oder Frost (.claude) – steuert Karten-, Knoten- und Wisp-Farbe
    var actor: Actor { get }
    func respond(system: String, messages: [ProviderMessage], tools: [ToolSpec]) async throws -> ProviderResponse
}

final class FakeProvider: ModelProvider, @unchecked Sendable {
    let name = "Fake"
    let actor: Actor
    private let script: [ProviderResponse]
    private(set) var received: [(system: String, messages: [ProviderMessage], tools: [ToolSpec])] = []
    private var calls = 0
    init(script: [ProviderResponse], actor: Actor = .local) {
        self.script = script; self.actor = actor
    }
    func respond(system: String, messages: [ProviderMessage], tools: [ToolSpec]) async throws -> ProviderResponse {
        received.append((system, messages, tools))
        let r = script[min(calls, script.count - 1)]
        calls += 1
        return r
    }
}
```

- [ ] **Schritt 2: Implementierung**
```swift
import Foundation

struct Grant: Identifiable, Equatable, Sendable {
    let id: UUID
    let name: String
    let url: URL
}

struct FileEntry: Codable, Sendable, Equatable {
    let relPath: String
    let name: String
    let isFolder: Bool
    let byteSize: Int?
}

enum FileError: Error, Equatable {
    case outsideSandbox, notFound, notAFolder, isFolder
    case unsupportedFormat, existsNeedsConfirmation, ioFailure(String)
}

struct FileTools: Sendable {
    let roots: [Grant]

    /// Löst „FreigabeName/rest/pfad" zu einer URL **innerhalb** dieser Freigabe auf.
    /// Liefert nil bei Fluchtversuch („..", absoluter Pfad, unbekannte Freigabe).
    func resolve(_ relPath: String) -> URL? {
        var comps = relPath.split(separator: "/").map(String.init)
        guard let firstName = comps.first,
              let root = roots.first(where: { $0.name == firstName })
        else { return nil }
        comps.removeFirst()
        var stack: [String] = []
        for c in comps {
            if c == "." { continue }
            if c == ".." { guard !stack.isEmpty else { return nil }; stack.removeLast() }
            else { stack.append(c) }
        }
        let url = stack.reduce(root.url) { $0.appendingPathComponent($1) }
        // ponytail: Containment doppelt – lexikalisch oben, hier real (dekodiert, Symlinks aufgelöst)
        let rootPath = root.url.resolvingSymlinksInPath().path
        let realPath = url.resolvingSymlinksInPath().path
        guard realPath == rootPath || realPath.hasPrefix(rootPath + "/") else { return nil }
        return url
    }

        guard let url = resolve(relPath) else { throw FileError.outsideSandbox }
        var isDir: ObjCBool = false
        guard FileManager.default.fileExists(atPath: url.path, isDirectory: &isDir) else { throw FileError.notFound }
        guard isDir.boolValue else { throw FileError.notAFolder }
        let items = try FileManager.default.contentsOfDirectory(
            at: url, includingPropertiesForKeys: [.isDirectoryKey, .fileSizeKey])
        return items
            .filter { !$0.lastPathComponent.hasPrefix(".") }
            .map { entry($0, rootName: rootName(of: relPath)) }
    }

    private func entry(_ url: URL, rootName: String) -> FileEntry {
        let values = try? url.resourceValues(forKeys: [.isDirectoryKey, .fileSizeKey])
        let rel = relPath(of: url)
        return FileEntry(relPath: rel, name: url.lastPathComponent,
                         isFolder: values?.isDirectory ?? false, byteSize: values?.fileSize)
    }

    private func rootName(of relPath: String) -> String {
        String(relPath.split(separator: "/").first ?? "")
    }

    func relPath(of url: URL) -> String {
        let real = url.resolvingSymlinksInPath().path
        for root in roots {
            let rootPath = root.url.resolvingSymlinksInPath().path
            guard real == rootPath || real.hasPrefix(rootPath + "/") else { continue }
            let sub = real == rootPath ? "" : String(real.dropFirst(rootPath.count + 1))
            return sub.isEmpty ? root.name : "\(root.name)/\(sub)"
        }
        return url.lastPathComponent
    }
```

```swift
    static let maxReadBytes = 200_000
    static let textExtensions: Set<String> = ["txt","md","csv","json","log","swift","py","html","xml","yml","yaml"]

    func read(_ relPath: String) throws -> String {
        guard let url = resolve(relPath) else { throw FileError.outsideSandbox }
        var isDir: ObjCBool = false
        guard FileManager.default.fileExists(atPath: url.path, isDirectory: &isDir) else { throw FileError.notFound }
        if isDir.boolValue { throw FileError.isFolder }
        let ext = url.pathExtension.lowercased()
        let content: String
        if ext == "pdf" {
            guard let doc = PDFDocument(url: url), let text = doc.string, !text.isEmpty else { throw FileError.unsupportedFormat }
            content = text
        } else if Self.textExtensions.contains(ext) {
            let data = FileManager.default.contents(atPath: url.path) ?? Data()
            if data.count > Self.maxReadBytes {
                return String(decoding: data.prefix(Self.maxReadBytes), as: UTF8.self)
                    + "\n[… Datei zu groß, Rest abgeschnitten]"
            }
            content = String(decoding: data, as: UTF8.self)
        } else { throw FileError.unsupportedFormat }
        if content.count > Self.maxReadBytes {
            return String(content.prefix(Self.maxReadBytes)) + "\n[… Datei zu groß, Rest abgeschnitten]"
        }
        return content
    }

    func search(nameContains: String, contentContains: String?) throws -> [FileEntry] {
        var hits: [FileEntry] = []
        for root in roots {
            let enums = FileManager.default.enumerator(at: root.url, includingPropertiesForKeys: [.isDirectoryKey])
            while let raw = enums?.nextObject() as? URL {
                let name = raw.lastPathComponent
                if name.hasPrefix(".") { continue }
                if !nameContains.isEmpty && !name.localizedCaseInsensitiveContains(nameContains) { continue }
                if let contentContains, !contentContains.isEmpty {
                    let rel = relPath(of: raw)
                    guard let text = try? read(rel), text.localizedCaseInsensitiveContains(contentContains) else { continue }
                }
                hits.append(entry(raw, rootName: root.name))
            }
        }
        return hits.sorted { $0.relPath < $1.relPath }
    }
```

```swift
    @discardableResult
    func write(_ relPath: String, content: String, overwrite: Bool, backupDir: URL) throws -> ActionCard? {
        guard let url = resolve(relPath) else { throw FileError.outsideSandbox }
        let exists = FileManager.default.fileExists(atPath: url.path)
        if exists && !overwrite { throw FileError.existsNeedsConfirmation }
        var backupCard: ActionCard? = nil
        if exists {
            try FileManager.default.createDirectory(at: backupDir, withIntermediateDirectories: true)
            let backupURL = backupDir.appendingPathComponent("\(UUID().uuidString)-\(url.lastPathComponent)")
            try FileManager.default.copyItem(at: url, to: backupURL)
            backupCard = ActionCard(id: UUID(), kind: .backup, actor: nil, title: "Sicherung vor Überschreiben",
                                     detail: backupURL.lastPathComponent, durationMS: nil, createdAt: Date())
        }
        try FileManager.default.createDirectory(at: url.deletingLastPathComponent(), withIntermediateDirectories: true)
        try content.write(to: url, atomically: true, encoding: .utf8)
        return backupCard
    }

    func rename(_ relPath: String, to newName: String) throws -> String {
        guard let url = resolve(relPath) else { throw FileError.outsideSandbox }
        guard !newName.contains("/"), !newName.hasPrefix(".") else { throw FileError.outsideSandbox }
        guard FileManager.default.fileExists(atPath: url.path) else { throw FileError.notFound }
        let target = url.deletingLastPathComponent().appendingPathComponent(newName)
        guard !FileManager.default.fileExists(atPath: target.path) else { throw FileError.existsNeedsConfirmation }
        do { try FileManager.default.moveItem(at: url, to: target) }
        catch { throw FileError.ioFailure(error.localizedDescription) }
        return self.relPath(of: target)   // self.: Parameter relPath schattiert die Methode
    }

    func move(_ relPath: String, toFolder: String) throws -> String {
        guard let url = resolve(relPath) else { throw FileError.outsideSandbox }
        guard let folderURL = resolve(toFolder) else { throw FileError.outsideSandbox }
        var isDir: ObjCBool = false
        guard FileManager.default.fileExists(atPath: folderURL.path, isDirectory: &isDir), isDir.boolValue else { throw FileError.notAFolder }
        let target = folderURL.appendingPathComponent(url.lastPathComponent)
        guard !FileManager.default.fileExists(atPath: target.path) else { throw FileError.existsNeedsConfirmation }
        do { try FileManager.default.moveItem(at: url, to: target) }
        catch { throw FileError.ioFailure(error.localizedDescription) }
        return self.relPath(of: target)   // self.: Parameter relPath schattiert die Methode
    }
```

```swift
import Foundation
import Security

struct BookmarkRecord: Codable {
    let id: UUID
    let name: String
    let data: Data
}

final class SecurityStore: @unchecked Sendable {
    static let storageKey = "hugin.grants"
    private let defaults: UserDefaults
    private let service = "com.hugin.app"

    init(defaults: UserDefaults = .standard) { self.defaults = defaults }

    @discardableResult
    func addGrant(url: URL) throws -> Grant {
        let scoped = url.startAccessingSecurityScopedResource()
        defer { if scoped { url.stopAccessingSecurityScopedResource() } }
        let data = try url.bookmarkData()
        var records = Self.decode(defaults.data(forKey: Self.storageKey))
        guard !records.contains(where: { $0.name == url.lastPathComponent }) else {
            throw FileError.ioFailure("Ordner mit diesem Namen ist bereits freigegeben")
        }
        let grant = Grant(id: UUID(), name: url.lastPathComponent, url: url)
        records.append(BookmarkRecord(id: grant.id, name: grant.name, data: data))
        defaults.set(try JSONEncoder().encode(records), forKey: Self.storageKey)
        return grant
    }

    func loadGrants() -> (grants: [Grant], skipped: Int) {
        var grants: [Grant] = []
        var skipped = 0
        for record in Self.decode(defaults.data(forKey: Self.storageKey)) {
            var stale = false
            guard let url = try? URL(resolvingBookmarkData: record.data, relativeTo: nil,
                                     bookmarkDataIsStale: &stale), !stale else { skipped += 1; continue }
            // Zugriff bleibt bewusst für die App-Lebenszeit aktiv (ein start pro Grant, kein stop)
            _ = url.startAccessingSecurityScopedResource()
            grants.append(Grant(id: record.id, name: record.name, url: url))
        }
        return (grants, skipped)
    }

    private static func decode(_ data: Data?) -> [BookmarkRecord] {
        guard let data else { return [] }
        return (try? JSONDecoder().decode([BookmarkRecord].self, from: data)) ?? []
    }

    // MARK: Keychain (Claude-API-Key)
    private var query: [String: Any] {
        [kSecClass as String: kSecClassGenericPassword,
         kSecAttrService as String: service,
         kSecAttrAccount as String: "claude",
         kSecAttrAccessible as String: kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly]
    }

    func saveKey(_ key: String) throws {
        SecItemDelete(query as CFDictionary)
        var add = query
        add[kSecValueData as String] = Data(key.utf8)
        let status = SecItemAdd(add as CFDictionary, nil)
        guard status == errSecSuccess else { throw ModelError.network("Keychain-Fehler \(status)") }
    }

    func loadKey() -> String? {
        var q = query
        q[kSecReturnData as String] = true
        q[kSecMatchLimit as String] = kSecMatchLimitOne
        var out: AnyObject?
        guard SecItemCopyMatching(q as CFDictionary, &out) == errSecSuccess,
              let data = out as? Data else { return nil }
        return String(decoding: data, as: UTF8.self)
    }

    func removeKey() { SecItemDelete(query as CFDictionary) }
}
```

```swift
import Foundation

final class ClaudeClient: ModelProvider, @unchecked Sendable {
    let name = "Claude"
    let actor: Actor = .claude   // Frost
    private let apiKey: String
    private let model: String
    private let session: URLSession

    init(apiKey: String, model: String = "claude-sonnet-4-5", session: URLSession = URLSession(configuration: .ephemeral)) {
        self.apiKey = apiKey; self.model = model; self.session = session
    }

    func respond(system: String, messages: [ProviderMessage], tools: [ToolSpec]) async throws -> ProviderResponse {
        var req = URLRequest(url: URL(string: "https://api.anthropic.com/v1/messages")!)
        req.httpMethod = "POST"
        req.setValue(apiKey, forHTTPHeaderField: "x-api-key")
        req.setValue("2023-06-01", forHTTPHeaderField: "anthropic-version")
        req.setValue("application/json", forHTTPHeaderField: "content-type")
        req.httpBody = try encodeBody(system: system, messages: messages, tools: tools)
        let data: Data; let resp: URLResponse
        do { (data, resp) = try await session.data(for: req) }
        catch let urlError as URLError where urlError.code == .cancelled {
            throw CancellationError()   // „Anhalten" bleibt „Angehalten", kein Fake-Netzwerkfehler
        }
        catch is CancellationError { throw CancellationError() }
        catch { throw ModelError.network(error.localizedDescription) }
        guard let http = resp as? HTTPURLResponse else { throw ModelError.network("Keine HTTP-Antwort") }
        guard http.statusCode == 200 else {
            if http.statusCode == 401 { throw ModelError.unauthorized }
            throw ModelError.network("HTTP \(http.statusCode)")
        }
        return try Self.parse(data)
    }

    private func encodeBody(system: String, messages: [ProviderMessage], tools: [ToolSpec]) throws -> Data {
        var msgs: [JSONValue] = []
        for m in messages {
            switch m {
            case .user(let t):
                msgs.append(.object(["role": .string("user"), "content": .string(t)]))
            case .assistant(let t, let calls):
                var blocks: [JSONValue] = []
                if !t.isEmpty {
                    blocks.append(.object(["type": .string("text"), "text": .string(t)]))
                }
                for c in calls {
                    blocks.append(.object(["type": .string("tool_use"), "id": .string(c.id),
                                            "name": .string(c.name), "input": c.arguments]))
                }
                if blocks.isEmpty { blocks.append(.object(["type": .string("text"), "text": .string("")])) }
                msgs.append(.object(["role": .string("assistant"), "content": .array(blocks)]))
            case .toolResult(let id, let content):
                msgs.append(.object(["role": .string("user"), "content": .array([
                    .object(["type": .string("tool_result"), "tool_use_id": .string(id), "content": .string(content)])])]))
            }
        }
        let toolsJSON: [JSONValue] = tools.map {
            .object(["name": .string($0.name), "description": .string($0.description), "input_schema": $0.inputSchema])
        }
        let body: JSONValue = .object([
            "model": .string(model), "max_tokens": .number(4096),
            "system": .string(system), "messages": .array(msgs), "tools": .array(toolsJSON)
        ])
        return try body.data()
    }

    static func parse(_ data: Data) throws -> ProviderResponse {
        let root = try JSONValue.from(data: data)
        var text = ""
        var calls: [ToolCall] = []
        guard case .array(let blocks)? = root["content"] else { return ProviderResponse(text: "", toolCalls: []) }
        for b in blocks {
            switch b["type"]?.stringValue {
            case "text": text += b["text"]?.stringValue ?? ""
            case "tool_use":
                calls.append(ToolCall(id: b["id"]?.stringValue ?? UUID().uuidString,
                                      name: b["name"]?.stringValue ?? "",
                                      arguments: b["input"] ?? .object([:])))
            default: break
            }
        }
        return ProviderResponse(text: text, toolCalls: calls)
    }
}

extension URLRequest {
    var httpBodyStreamData: Data? {
        guard let stream = httpBodyStream else { return nil }
        stream.open(); defer { stream.close() }
        var data = Data(); let bufSize = 4096
        let buf = UnsafeMutablePointer<UInt8>.allocate(capacity: bufSize)
        defer { buf.deallocate() }
        while stream.hasBytesAvailable {
            let read = stream.read(buf, maxLength: bufSize)
            if read <= 0 { break }
            data.append(buf, count: read)
        }
        return data
    }
}
```

```swift
import Foundation
import FoundationModels

final class AppleSystemModel: ModelProvider, @unchecked Sendable {
    let name = "Apple On-Device"
    let actor: Actor = .local   // Glut
    private let fileTools: FileTools
    private let backupDir: URL
    private let onCard: @Sendable (ActionCard) -> Void
    private let onFinding: @Sendable (Finding) -> Void
    private let confirm: @Sendable (ConfirmRequest) async -> Bool

    init?(fileTools: FileTools, backupDir: URL,
          onCard: @Sendable (ActionCard) -> Void,
          onFinding: @Sendable (Finding) -> Void,
          confirm: @Sendable (ConfirmRequest) async -> Bool) {
        guard SystemLanguageModel.isAvailable else { return nil }
        self.fileTools = fileTools; self.backupDir = backupDir
        self.onCard = onCard; self.onFinding = onFinding; self.confirm = confirm
    }

    func respond(system: String, messages: [ProviderMessage], tools: [ToolSpec]) async throws -> ProviderResponse {
        guard SystemLanguageModel.isAvailable else { throw ModelError.unavailable }
        let box = ToolBox(fileTools: fileTools, backupDir: backupDir, onCard: onCard,
                          onFinding: onFinding, confirm: confirm)
        let session = LanguageModelSession(instructions: Instructions(instructions: system),
                                            tools: [box.listFiles, box.searchFiles, box.readFile,
                                                    box.writeFile, box.renameFile, box.moveFile,
                                                    box.noteFinding])
        let prompt = Self.transcript(messages: messages)
        let response = try await session.respond(to: prompt)
        return ProviderResponse(text: response.content, toolCalls: [])
    }

    static func transcript(messages: [ProviderMessage]) -> String {
        messages.map {
            switch $0 {
            case .user(let t): return "Nutzer: \(t)"
            case .assistant(let t, _): return "Agent: \(t)"
            case .toolResult(_, let c): return "Beobachtung: \(c)"
            }
        }.joined(separator: "\n")
    }
}

private final class ToolBox: @unchecked Sendable {
    let fileTools: FileTools
    let backupDir: URL
    let onCard: @Sendable (ActionCard) -> Void
    let onFinding: @Sendable (Finding) -> Void
    let confirm: @Sendable (ConfirmRequest) async -> Bool

    init(fileTools: FileTools, backupDir: URL,
         onCard: @Sendable (ActionCard) -> Void,
         onFinding: @Sendable (Finding) -> Void,
         confirm: @Sendable (ConfirmRequest) async -> Bool) {
        self.fileTools = fileTools; self.backupDir = backupDir
        self.onCard = onCard; self.onFinding = onFinding; self.confirm = confirm
    }

    private func emit(_ kind: CardKind, _ title: String, _ detail: String, since t0: Date) {
        onCard(ActionCard(id: UUID(), kind: kind, actor: .local, title: title, detail: detail,
                          durationMS: Int(Date().timeIntervalSince(t0) * 1000), createdAt: Date()))
    }

    @GenerableTool(description: "Listet Dateien eines Ordners. folder = relativer Pfad inkl. Freigabe-Name (z. B. 'Doku').")
    func listFiles(folder: String) async -> String {
        let t0 = Date()
        do {
            let entries = try fileTools.list(folder: folder)
            emit(.list, "Ordner gelistet", folder, since: t0)
            return entries.isEmpty ? "Ordner ist leer."
                : entries.map { $0.isFolder ? "[Ordner] \($0.relPath)" : $0.relPath }.joined(separator: "\n")
        } catch { return "Fehler: \(error)" }
    }

    @GenerableTool(description: "Durchsucht Dateien nach Namen und optional nach Inhalt.")
    func searchFiles(nameContains: String, contentContains: String?) async -> String {
        let t0 = Date()
        do {
            let hits = try fileTools.search(nameContains: nameContains, contentContains: contentContains)
            emit(.search, "Suche: '\(nameContains)'", "\(hits.count) Treffer", since: t0)
            return hits.map(\.relPath).joined(separator: "\n").isEmpty ? "Keine Treffer."
                : hits.map(\.relPath).joined(separator: "\n")
        } catch { return "Fehler: \(error)" }
    }

    @GenerableTool(description: "Liest den Inhalt einer Datei (Text oder PDF). path = relativer Pfad inkl. Freigabe-Name.")
    func readFile(path: String) async -> String {
        let t0 = Date()
        do {
            let text = try fileTools.read(path)
            emit(.read, "Datei gelesen", path, since: t0)
            return text
        } catch { return "Fehler: \(error)" }
    }

    @GenerableTool(description: "Erstellt/überschreibt eine Datei. Vor Überschreiben wird der Nutzer gefragt und ein Backup erstellt.")
    func writeFile(path: String, content: String) async -> String {
        let t0 = Date()
        do {
            let exists = fileTools.resolve(path).map { FileManager.default.fileExists(atPath: $0.path) } ?? false
            if exists {
                let old = try? fileTools.read(path)
                let request = ConfirmRequest(path: path, oldContent: old, newContent: content)
                guard await confirm(request) else { return "Nutzer hat Überschreiben abgelehnt." }
            }
            if let card = try fileTools.write(path, content: content, overwrite: exists, backupDir: backupDir) {
                onCard(card)
            }
            emit(.write, exists ? "Datei überschrieben" : "Datei geschrieben", path, since: t0)
            return "Geschrieben: \(path)"
        } catch { return "Fehler: \(error)" }
    }

    @GenerableTool(description: "Benennt eine Datei um (kein Pfad im neuen Namen).")
    func renameFile(path: String, newName: String) async -> String {
        let t0 = Date()
        do {
            let rel = try fileTools.rename(path, to: newName)
            emit(.rename, "Umbenannt", "\(path) → \(rel)", since: t0)
            return "Neuer Pfad: \(rel)"
        } catch { return "Fehler: \(error)" }
    }

    @GenerableTool(description: "Verschiebt eine Datei in einen anderen Ordner (innerhalb der Freigaben).")
    func moveFile(path: String, toFolder: String) async -> String {
        let t0 = Date()
        do {
            let rel = try fileTools.move(path, toFolder: toFolder)
            emit(.move, "Verschoben", "\(path) → \(rel)", since: t0)
            return "Neuer Pfad: \(rel)"
        } catch { return "Fehler: \(error)" }
    }

    @GenerableTool(description: "Meldet einen gefundenen Wert (Beträge, Namen, Daten) für das Fundstück-Panel.")
    func noteFinding(name: String, value: String) async -> String {
        onFinding(Finding(id: UUID(), name: name, value: value, actor: .local, createdAt: Date()))
        return "Notiert: \(name) = \(value)"
    }
}
```

```swift
            performedCalls += batch.count

            for call in batch {
                let (obs, cards) = await execute(call)
                produced += cards
                messages.append(.toolResult(id: call.id, content: obs))
            }
        }
        return .limitReached(text: "Werkzeug-Limit (\(Self.maxSteps)) erreicht – Aufgabe abgebrochen.", cards: produced)
    }

    private func execute(_ call: ToolCall) async -> (String, [ActionCard]) {
        let t0 = Date()
        let arg = call.arguments
        func str(_ key: String) -> String { arg[key]?.stringValue ?? "" }
        var cards: [ActionCard] = []
        func card(_ kind: CardKind, _ title: String, _ detail: String) {
            let c = ActionCard(id: UUID(), kind: kind, actor: provider.actor, title: title, detail: detail,
                               durationMS: Int(Date().timeIntervalSince(t0) * 1000), createdAt: Date())
            cards.append(c); onCard(c)
        }
        do {
            switch call.name {
            case "list_files":
                let entries = try fileTools.list(folder: str("folder"))
                card(.list, "Ordner gelistet", str("folder"))
                return (entries.isEmpty ? "Ordner ist leer."
                        : entries.map { $0.isFolder ? "[Ordner] \($0.relPath)" : $0.relPath }.joined(separator: "\n"), cards)
            case "search_files":
                let hits = try fileTools.search(nameContains: str("nameContains"),
                                               contentContains: str("contentContains").ifEmpty(nil))
                card(.search, "Suche: '\(str("nameContains"))'", "\(hits.count) Treffer")
                return (hits.map(\.relPath).joined(separator: "\n").ifEmpty("Keine Treffer."), cards)
            case "read_file":
                let text = try fileTools.read(str("path"))
                card(.read, "Datei gelesen", str("path"))
                return (text, cards)
            case "write_file":
                let path = str("path")
                let exists = fileTools.resolve(path).map { FileManager.default.fileExists(atPath: $0.path) } ?? false
                // Gate hängt NIE am LLM-Argument 'overwrite': Jede existierende Datei wird
                // bestätigt (Prompt-Injection-Schutz); ConfirmRequest liefert alt/neu für den Diff
                if exists {
                    let old = try? fileTools.read(path)
                    let request = ConfirmRequest(path: path, oldContent: old, newContent: str("content"))
                    guard await confirm(request) else {
                        card(.hint, "Überschreiben abgelehnt", path)
                        return ("Nutzer hat Überschreiben abgelehnt.", cards)
                    }
                }
                if let backupCard = try fileTools.write(path, content: str("content"),
                                                        overwrite: exists, backupDir: backupDir) {
                    onCard(backupCard); cards.append(backupCard)
                }
                card(.write, exists ? "Datei überschrieben" : "Datei geschrieben", path)
                return ("Geschrieben: \(path)", cards)
            case "rename_file":
                let rel = try fileTools.rename(str("path"), to: str("newName"))
                card(.rename, "Umbenannt", "\(str("path")) → \(rel)")
                return ("Neuer Pfad: \(rel)", cards)
            case "move_file":
                let rel = try fileTools.move(str("path"), toFolder: str("toFolder"))
                card(.move, "Verschoben", "\(str("path")) → \(rel)")
                return ("Neuer Pfad: \(rel)", cards)
            case "note_finding":
                let finding = Finding(id: UUID(), name: str("name"), value: str("value"),
                                      actor: provider.actor, createdAt: Date())
                onFinding(finding)
                return ("Notiert: \(finding.name) = \(finding.value)", cards)
            default:
                return ("Unbekanntes Werkzeug: \(call.name)", cards)
            }
        } catch {
            card(.error, "Werkzeugfehler", "\(call.name): \(error)")
            return ("Fehler: \(error)", cards)
        }
    }
```

```swift
import SwiftUI
import Observation

@MainActor
@Observable
final class ChatViewModel {
    enum Mode: String, Codable { case auto, onDevice, claude }
    enum Status: Equatable { case idle, thinking, error(String) }

    struct Confirmation: Identifiable {
        let id = UUID()
        let request: ConfirmRequest   // Pfad + alt/neu für Diff im Halten-Dialog
        var continuation: CheckedContinuation<Bool, Never>?
    }

    struct RunningInfo: Equatable {
        let actor: Actor
        var step: Int          // var: Live-Mirror inkrementiert je Werkzeugaufruf
        let startedAt: Date
    }

    private(set) var munin: [OrderSummary] = []   // Auftrags-Historie
    var currentOrderID: UUID?                     // nil = Start-Screen
    var messages: [ChatMessage] = []
    var status: Status = .idle
    var mode: Mode = UserDefaults.standard.string(forKey: "hugin.mode").flatMap(Mode.init(rawValue:)) ?? .auto {
        didSet { UserDefaults.standard.set(mode.rawValue, forKey: "hugin.mode") }
    }
    var grants: [Grant] = []
    var draft = ""
    var queuedDraft: String?                     // „Nächsten Auftrag vormerken …"
    var running: RunningInfo?                    // Running-Pill (Akteur, Schritt, Zeit)
    var liveCards: [ActionCard] = []            // Flugbahn während des Laufs („● live“)
    var liveFindings: [Finding] = []            // Fundstück während des Laufs
    var pendingConfirmation: Confirmation?

    private let security: SecurityStore
    private let store: HuginStore?
    // @MainActor-Closure, IUO: Zuweisung NACH allen anderen Properties (self-Capture erst dann erlaubt);
    // CardBuffer/FindingBuffer laufen als Parameter mit – kein MainActor-State aus @Sendable-Closures gelesen
    private var makeProvider: (@MainActor (Mode, CardBuffer, FindingBuffer) throws -> ModelProvider)!
    private var runTask: Task<Void, Never>?

    init(security: SecurityStore = SecurityStore(),
         store: HuginStore? = nil,
         makeProvider: (@MainActor (Mode, CardBuffer, FindingBuffer) throws -> ModelProvider)? = nil) {
        self.security = security
        self.store = store
        self.makeProvider = makeProvider ?? { [weak self] mode, cards, findings in
            guard let self else { throw ModelError.network("ViewModel nicht mehr verfügbar") }
            switch mode {
            case .onDevice:
                guard let onDevice = AppleSystemModel(fileTools: self.fileTools(),
                                                      backupDir: self.backupDir,
                                                      onCard: { cards.add($0) },
                                                      onFinding: { findings.add($0) },
                                                      confirm: self.confirmBridge) else {
                    throw ModelError.unavailable
                }
                return onDevice
            case .claude, .auto:
                guard let key = self.security.loadKey() else { throw ModelError.unauthorized }
                return ClaudeClient(apiKey: key)
            }
        }
    }

    func load() {
        let (loaded, skipped) = security.loadGrants()
        grants = loaded
        if skipped > 0 && loaded.isEmpty {
            status = .error("Alle Freigaben abgelaufen – bitte Ordner neu freigeben.")
        }
        if let store { munin = store.listOrders() }
    }

    /// Munin-Eintrag antippen: Auftrag einsehen (read-only; Fortsetzung = neuer Auftrag)
    func open(orderID: UUID) {
        currentOrderID = orderID
        messages = store?.load(orderID: orderID) ?? []
        status = .idle
        running = nil
    }

    /// Zurück zum Start-Screen
    func closeOrder() {
        currentOrderID = nil
        messages = []
        status = .idle
    }

    /// „Anhalten" (Design: Stop-Knopf in der Auftragsleiste)
    func stop() { runTask?.cancel() }

    func addGrant(url: URL) {
        do { _ = try security.addGrant(url: url); grants = security.loadGrants() }
        catch { status = .error("Freigabe fehlgeschlagen: \(error)") }
    }

    func saveKey(_ key: String) {
        do { try security.saveKey(key) } catch { status = .error("Key speichern fehlgeschlagen: \(error)") }
    }

    private var backupDir: URL {
        FileManager.default.urls(for: .documentDirectory, in: .userDomainMask)[0]
            .appendingPathComponent(".backups")
    }

    private func fileTools() -> FileTools {
        FileTools(roots: security.loadGrants().grants)
    }

    func run(_ text: String) {
        guard status != .thinking else { return }
        // Einmal-Override aus dem Auftragstext (Spec: „nutz Claude“/„nutz lokal“)
        var modeForRun = mode
        var prompt = text
        let lower = text.lowercased()
        if lower.contains("nutz claude") {
            modeForRun = .claude
            prompt = prompt.replacingOccurrences(of: "nutz Claude", with: "", options: .caseInsensitive)
        } else if lower.contains("nutz lokal") || lower.contains("nutz on-device") {
            modeForRun = .onDevice
            prompt = prompt.replacingOccurrences(of: "nutz lokal", with: "", options: .caseInsensitive)
                .replacingOccurrences(of: "nutz on-device", with: "", options: .caseInsensitive)
        }
        // Neuer Auftrag (Munin-Eintrag), frischer Verlauf
        let orderID = UUID()
        currentOrderID = orderID
        messages = [ChatMessage(role: .user, text: text)]
        let title = String(text.prefix(48))
        running = nil
        status = .thinking
        runTask = Task { [weak self] in
            guard let self else { return }
            await self.executeRun(orderID: orderID, title: title, prompt: prompt, modeForRun: modeForRun)
        }
    }

    /// „Nächsten Auftrag schon vormerken …“ (Queue-Bar, Design-Auftragsansicht)
    func queueDraft(_ text: String) {
        guard !text.isEmpty else { return }
        queuedDraft = text
    }

    private func startQueuedIfAny() {
        guard status != .thinking, let next = queuedDraft else { return }
        queuedDraft = nil
        run(next)
    }

    func waitForRunEnd() async {
        await runTask?.value
    }

    private func executeRun(orderID: UUID, title: String, prompt: String, modeForRun: Mode) async {
        let cards = CardBuffer()
        let findings = FindingBuffer()
        liveCards = []; liveFindings = []
        defer { running = nil; status = .idle; startQueuedIfAny() }
        do {
            let (provider, hint) = try resolveProvider(mode: modeForRun, cards: cards, findings: findings)
            if let hint { cards.add(hint); liveCards.append(hint) }
            running = RunningInfo(actor: provider.actor, step: 0, startedAt: Date())
            let (finalText, stepCards, found) = try await runAgent(
                provider: provider, cards: cards, findings: findings, text: prompt)
            messages.append(ChatMessage(role: .assistant, text: finalText, cards: stepCards, findings: found))
            liveCards = []; liveFindings = []
            persist(orderID: orderID, title: title, actor: provider.actor)
        } catch is CancellationError {
            messages.append(ChatMessage(role: .assistant, text: "Angehalten.", cards: cards.all, findings: findings.all))
            liveCards = []; liveFindings = []
            persist(orderID: orderID, title: title, actor: nil)
        } catch let urlError as URLError where urlError.code == .cancelled {
            // Abbruch während eines Netzaufrufs → ebenfalls „Angehalten“, kein Fake-Fehler
            messages.append(ChatMessage(role: .assistant, text: "Angehalten.", cards: cards.all, findings: findings.all))
            liveCards = []; liveFindings = []
            persist(orderID: orderID, title: title, actor: nil)
        } catch {
            // Laufzeit-Eskalation (nur auto): onDevice-Modell versagt mitten im Lauf → Claude.
            // Init-Fälle eskaliert resolveProvider bereits; Claude-Netzwerk-/Key-Fehler → klare
            // Meldung, on-device bleibt über den Botengang nutzbar (Spec: „Kein Internet → nur on-device“)
            if modeForRun == .auto, (error as? ModelError) == .unavailable,
               let claude = try? makeProvider(.claude, cards, findings) {
                let handover = ActionCard(id: UUID(), kind: .handover, actor: .claude,
                                          title: "Übergabe: On-Device fehlgeschlagen – Claude übernimmt",
                                          detail: "\(error)", durationMS: nil, createdAt: Date())
                cards.add(handover); liveCards.append(handover)
                do {
                    running = RunningInfo(actor: .claude, step: 0, startedAt: Date())
                    let (finalText, stepCards, found) = try await runAgent(
                        provider: claude, cards: cards, findings: findings, text: prompt)
                    messages.append(ChatMessage(role: .assistant, text: finalText,
                                               cards: cards.all, findings: findings.all))
                    liveCards = []; liveFindings = []
                    persist(orderID: orderID, title: title, actor: .claude)
                    return   // defer übernimmt running/status/Queue
                } catch { /* fällt unten in die Fehlermeldung durch */ }
            }
            let errorCard = ActionCard(id: UUID(), kind: .error, actor: nil, title: "Fehler",
                                       detail: "\(error)", durationMS: nil, createdAt: Date())
            messages.append(ChatMessage(role: .assistant, text: errorText(error),
                                       cards: cards.all + [errorCard], findings: findings.all))
            liveCards = []; liveFindings = []
            persist(orderID: orderID, title: title, actor: nil)
        }
    }

    private func persist(orderID: UUID, title: String, actor: Actor?) {
        guard let store else { return }
        let actorName = actor == .claude ? "Claude" : "lokal"
        try? store.save(orderID: orderID, title: title, actor: actorName, messages: messages)
        munin = store.listOrders()
    }

    private func runAgent(provider: ModelProvider, cards: CardBuffer, findings: FindingBuffer,
                          text: String) async throws -> (String, [ActionCard], [Finding]) {
        // Live-Spiegel über AsyncStream (Swift-6-sicher: Continuations sind Sendable,
        // kein MainActor-State aus @Sendable-Closures gelesen)
        let (cardStream, cardContinuation) = AsyncStream<ActionCard>.makeStream()
        let (findingStream, findingContinuation) = AsyncStream<Finding>.makeStream()
        let cardMirror = Task { @MainActor in
            for await card in cardStream {
                liveCards.append(card)
                running?.step += 1
            }
        }
        let findingMirror = Task { @MainActor in
            for await finding in findingStream { liveFindings.append(finding) }
        }
        defer {
            cardContinuation.finish(); findingContinuation.finish()
            cardMirror.cancel(); findingMirror.cancel()
        }
        let runner = AgentRunner(provider: provider, fileTools: fileTools(), backupDir: backupDir,
                                 onCard: { c in cards.add(c); cardContinuation.yield(c) },
                                 onFinding: { f in findings.add(f); findingContinuation.yield(f) },
                                 confirm: confirmBridge)
        let result = try await runner.run(userText: text, prior: [])
        let finalText: String
        switch result {
        case .completed(let t, _): finalText = t
        case .limitReached(let t, _): finalText = t
        }
        return (finalText, cards.all, findings.all)
    }

    private func resolveProvider(mode: Mode, cards: CardBuffer, findings: FindingBuffer)
        throws -> (ModelProvider, ActionCard?) {
        switch mode {
        case .onDevice:
            return (try makeProvider(.onDevice, cards, findings), nil)
        case .claude:
            return (try makeProvider(.claude, cards, findings), nil)
        case .auto:
            do { return (try makeProvider(.onDevice, cards, findings), nil) }
            catch {
                let handover = ActionCard(id: UUID(), kind: .handover, actor: .claude,
                                          title: "Übergabe: On-Device nicht möglich – Claude übernimmt",
                                          detail: "\(error)", durationMS: nil, createdAt: Date())
                return (try makeProvider(.claude, cards, findings), handover)
            }
        }
    }

    private lazy var confirmBridge: @Sendable (ConfirmRequest) async -> Bool = { [weak self] request in
        await MainActor.run {
            await withCheckedContinuation { (c: CheckedContinuation<Bool, Never>) in
                // Defensive: eine etwaige ältere Continuation freigeben (kein Deadlock/Leak)
                self?.pendingConfirmation?.continuation?.resume(returning: false)
                self?.pendingConfirmation = Confirmation(request: request, continuation: c)
            }
        }
    }

    private func errorText(_ error: Error) -> String {
        switch error as? ModelError {
        case .unauthorized: return "Claude-API-Key ungültig – bitte in den Einstellungen prüfen. On-Device-Modus bleibt nutzbar."
        case .network(let msg): return "Netzwerkfehler: \(msg). On-Device-Modus bleibt nutzbar."
        case .unavailable: return "On-Device-Modell nicht verfügbar."
        case nil: return "Fehler: \(error)"
        }
    }

    func resolveConfirmation(_ allowed: Bool) {
        pendingConfirmation?.continuation?.resume(returning: allowed)
        pendingConfirmation = nil
    }
}
```

```swift
import SwiftUI

enum WispState { case ruhe, denkt, fliegt, uebergabe, wartet, stockt, fertig }

struct WispView: View {
    let state: WispState
    let actor: Actor
    var size: CGFloat = 12
    @Environment(\.accessibilityReduceMotion) private var reduceMotion

    static func color(for state: WispState, actor: Actor) -> Color {
        switch state {
        case .wartet: return HuginColor.knochen
        case .stockt: return HuginColor.rost
        case .uebergabe: return HuginColor.frost
        default: return actor == .claude ? HuginColor.frost : HuginColor.glut
        }
    }

    var body: some View {
        let core = Self.color(for: state, actor: actor)
        ZStack {
            Circle().fill(core).frame(width: size, height: size)
            Circle().fill(core.opacity(0.42)).frame(width: size * 3, height: size * 3)
                .blur(radius: size * 0.5)
            switch state {
            case .denkt: sparkOrbit
            case .wartet: ripples
            default: EmptyView()
            }
        }
        .modifier(WispMotion(state: state, reduce: reduceMotion, size: size))
        .accessibilityHidden(true)
    }

    @ViewBuilder private var sparkOrbit: some View {
        Circle().fill(HuginColor.knochen).frame(width: size * 0.45, height: size * 0.45)
            .offset(y: -size * 1.2)
        // Umlauf via rotationEffect-Animation (1,4 s, linear, repeatForever)
    }

    @ViewBuilder private var ripples: some View {
        ForEach(0..<2, id: \.self) { i in
            Circle().stroke(HuginColor.knochen.opacity(0.7), lineWidth: 1.5)
                .frame(width: size, height: size)
        }
        // Skalierung 0,6→3,4 mit 1,6 s easeOut, zweiter Kreis 0,8 s versetzt
    }
}

private struct WispMotion: ViewModifier {
    let state: WispState
    let reduce: Bool
    @State private var pulse = false

    func body(content: Content) -> some View {
        content
            .scaleEffect(pulse ? 1.06 : 0.88)   // Atmen: 0,88–1,06 (Design §3)
            .animation(breathing, value: pulse)
            .onAppear { pulse.toggle() }         // startet den Atem-Zyklus
    }

    private var breathing: Animation? {
        guard !reduce else { return nil }        // ReduceMotion: nur Farb-Blend, keine Bewegung
        switch state {
        case .ruhe, .wartet: return HuginMotion.atmen                       // 4,2 s ∞
        case .denkt: return .easeInOut(duration: 1.1).repeatForever(autoreverses: true)
        case .stockt: return .linear(duration: 2.2).repeatForever(autoreverses: true)
        case .fertig: return HuginMotion.einsinken                          // 700 ms, einmalig
        default: return nil    // fliegt/uebergabe: Bewegung sitzt in Stage-Logik/Übergang
        }
    }
}
```

```swift
import SwiftUI

struct StepNode: View {
    let card: ActionCard
    var isRunning: Bool = false

    static func label(for kind: CardKind) -> String {
        switch kind {
        case .list: "AUFLISTEN"; case .search: "SUCHEN"; case .read: "LESEN"
        case .write: "SCHREIBEN"; case .rename: "UMBENENNEN"; case .move: "VERSCHIEBEN"
        case .handover: "ÜBERGABE"; case .backup: "SICHERUNG"
        case .error: "FEHLER"; case .hint: "HINWEIS"
        }
    }

    static func formatDuration(_ ms: Int?) -> String {
        guard let ms else { return "" }
        if ms < 60_000 {
            // Floor auf Zehntelsekunden – 59_999 ms bleibt „59,9 s" (kein Rundungs-Grenzbruch)
            let tenths = Int(floor(Double(ms) / 100.0))
            return String(format: "%.1f", Double(tenths) / 10)
                .replacingOccurrences(of: ".", with: ",") + " s"
        }
        return String(format: "%d:%02d", ms / 60_000, (ms % 60_000) / 1000)
    }

    var body: some View {
        HStack(alignment: .top, spacing: 0) {
            // Knoten: Kreis (Diamant bei Übergabe), Connector-Linie nach unten in Akteur-Farbe
            VStack(spacing: 6) {
                if isRunning {
                    WispView(state: .denkt, actor: card.actor ?? .local, size: 18)
                } else if card.kind == .handover {
                    RoundedRectangle(cornerRadius: 2).fill(HuginColor.glut)
                        .frame(width: 12, height: 12).rotationEffect(.degrees(45))
                        .overlay(RoundedRectangle(cornerRadius: 2).stroke(HuginColor.frost, lineWidth: 2))
                } else {
                    Circle().fill(nodeColor).frame(width: 14, height: 14)
                        .overlay(Circle().stroke(nodeColor.opacity(0.8), lineWidth: 2))
                }
                Rectangle().fill(connectorColor).frame(width: 2).frame(maxHeight: .infinity)
            }
            .frame(width: 40)
            HStack(alignment: .firstTextBaseline, spacing: 12) {
                monoText(Self.label(for: card.kind), size: 11, color: labelColor)
                    .frame(width: 92, alignment: .leading)
                Text(card.title).font(HuginFont.geist(15)).lineLimit(2)
                Spacer()
                monoText(isRunning ? "läuft" : Self.formatDuration(card.durationMS),
                         size: 11, color: isRunning ? HuginColor.frost : HuginColor.asche)
            }
        }
    }

    private var nodeColor: Color {
        card.kind == .error ? HuginColor.rost : HuginColor.actor(card.actor)
    }
    private var connectorColor: Color { HuginColor.actor(card.actor).opacity(0.42) }
    private var labelColor: Color {
        card.kind == .error ? HuginColor.rost : HuginColor.actor(card.actor)
```

```swift
import SwiftUI

struct DiffLine: Equatable {
    let sign: Character   // " ", "+", "-"
    let text: String
}

struct DiffView: View {
    let old: String?
    let new: String

    static func compute(old: String?, new: String) -> [DiffLine] {
        // UI-Schutz: LLM-Output ist untrusted – Diff kappen statt Dialog einfrieren
        let maxLines = 300
        let maxCharsPerLine = 1_000
        func cap(_ s: String) -> [String] {
            let lines = s.components(separatedBy: "\n")
            var capped = lines.prefix(maxLines).map { line in
                line.count > maxCharsPerLine
                    ? String(line.prefix(maxCharsPerLine)) + " …" : line
            }
            if lines.count > maxLines { capped.append("… (\(lines.count - maxLines) weitere Zeilen gekürzt)") }
            return Array(capped)
        }
        let oldLines = old.map { cap($0) } ?? []
        let newLines = cap(new)
        // Gemeinsamen Präfix/SUFFIX kappen (ponytail: einfacher Zeilen-Diff, kein LCS)
        var prefix = 0
        while prefix < oldLines.count && prefix < newLines.count && oldLines[prefix] == newLines[prefix] {
            prefix += 1
        }
        var suffix = 0
        while suffix < oldLines.count - prefix && suffix < newLines.count - prefix
                && oldLines[oldLines.count - 1 - suffix] == newLines[newLines.count - 1 - suffix] {
            suffix += 1
        }
        var result: [DiffLine] = []
        for i in 0..<prefix { result.append(DiffLine(sign: " ", text: newLines[i])) }
        for i in prefix..<(oldLines.count - suffix) { result.append(DiffLine(sign: "-", text: oldLines[i])) }
        for i in prefix..<(newLines.count - suffix) { result.append(DiffLine(sign: "+", text: newLines[i])) }
        for i in (newLines.count - suffix)..<newLines.count { result.append(DiffLine(sign: " ", text: newLines[i])) }
        return result
    }

    var body: some View {
        VStack(alignment: .leading, spacing: 0) {
            ForEach(Array(Self.compute(old: old, new: new).enumerated()), id: \.offset) { _, line in
                HStack(spacing: 14) {
                    Text(String(line.sign)).frame(width: 10)
                    Text(line.text)
                }
                .font(HuginFont.geistMono(13))
                // Design §5.4: − Text hell (Rost-Ton), + Text Knochen, Kontext Asche; Tint nur im Hintergrund
                .foregroundStyle(line.sign == "-" ? HuginColor.rostText
                                 : line.sign == "+" ? HuginColor.knochen
                                 : HuginColor.asche)
                .padding(.horizontal, 18).padding(.vertical, 7)
                .frame(maxWidth: .infinity, alignment: .leading)
                .background(line.sign == "-" ? HuginColor.rost.opacity(0.10)
                           : line.sign == "+" ? HuginColor.frost.opacity(0.07) : .clear)
            }
        }
        .background(RoundedRectangle(cornerRadius: 14).fill(Color(hex: 0x0F1013))
            .stroke(HuginColor.border1))
    }
}
```

```swift
struct HoldToConfirmButton: View {
    let onConfirmed: () -> Void
    static let holdSeconds: Double = 1.2
    @State private var progress: Double = 0

    @State private var holdTask: Task<Void, Never>?

            HStack(spacing: 14) {

                Text(label).font(HuginFont.geist(16, .semibold)).foregroundStyle(done ? HuginColor.glut : HuginColor.basalt)
                Spacer()
                monoText(done ? "✓" : "1,2 s", size: 12, color: HuginColor.basalt.opacity(0.6))
            }
            .padding(.leading, 10).padding(.trailing, 22)
        }
        .frame(height: 60)
        .gesture(DragGesture(minimumDistance: 0)
            .onChanged { _ in startHold() }
            .onEnded { _ in endHold() })
    }

    private var progressFraction: Double { done ? 1 : progress }
    private var totalWidth: CGFloat { 400 }   // Implementer: GeometryReader für echte Breite
    private var label: String {
        done ? "Überschrieben · Sicherung angelegt"
             : (progress > 0 ? "Weiter halten …" : "Zum Überschreiben halten")
    }

    private func startHold() {
        guard !done, holdTask == nil else { return }
        holdTask = Task { @MainActor in
            let t0 = Date()
            while !Task.isCancelled {
                progress = min(1, Date().timeIntervalSince(t0) / Self.holdSeconds)
                if progress >= 1 { done = true; onConfirmed(); holdTask = nil; return }
                try? await Task.sleep(for: .milliseconds(30))
            }
        }
    }
    private func endHold() {
        holdTask?.cancel(); holdTask = nil
        if !done { withAnimation(.easeOut(duration: 0.24)) { progress = 0 } }
    }
}
```
